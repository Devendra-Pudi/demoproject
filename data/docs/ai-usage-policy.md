# Approved AI tool usage policy
Employees may use the approved AI assistant for drafting, summarisation and code suggestions. Approved tools must never be given confidential customer data, credentials or unreleased financial results.

Every AI-assisted deliverable must be reviewed by the employee who submits it. The reviewer is accountable for accuracy, licensing and citations.

Requests to integrate a new AI vendor require security review and a data protection assessment before any pilot begins.
