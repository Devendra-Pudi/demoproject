# Screenshots

Real screenshots are produced by:

```bash
pip install playwright && playwright install chromium
python scripts/capture_screenshots.py
```

This directory is intentionally empty of images in the repository snapshot because the sandbox used
to build this portfolio had no browser available (the Playwright CDN download was blocked). Run the
script on any machine with a browser to fill it.

Until then, [`docs/previews/`](../previews) contains **structure previews** rendered from the
running apps — real labels and values, approximate styling, clearly labeled as not being screenshots.
